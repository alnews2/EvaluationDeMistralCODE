## [Unreleased]

### Added
- Initial project structure with PySide6 and Qt
- Task management system with CRUD operations
- Main application window with modern dark theme
- Task creation and editing dialogs
- Task filtering (all, pending, completed, overdue)
- Search functionality
- JSON-based persistence
- Unit tests for models and services
- UI tests with pytest-qt
- Pre-commit hooks for code quality
- GitHub Actions CI/CD pipeline

### Changed
- Architecture based on MVC pattern (Model-View-Controller)
- Separation of concerns between UI and business logic
- Signal/Slot mechanism for loose coupling

### Fixed
- Initial implementation - no bugs to report yet
